# Mobile App Design System

This document defines the design standards for the mobile app to ensure consistency across all screens and components.

## Color Palette
- Primary: #2D6AE3
- Secondary: #da221cff
- Accent: #FFB800
- Success: #2ECC40
- Error: #FF3B30
- Warning: #FF9500
- Text Primary: #222B45
- Text Secondary: #8F9BB3
- Background: #FFFFFF
- Card Background: #F5F6FA

## Typography
- Title: 20-24pt, Bold, Text Primary
- Subtitle: 16-18pt, Medium, Text Secondary
- Body: 14-16pt, Regular, Text Primary
- Caption: 12pt, Regular, Text Secondary

## Card Design
- Background: Card Background
- Border Radius: 12
- Shadow: Subtle, elevation 2
- Padding: 16
- Margin: 8-16 between cards

## Tabbed Interface
- Tab Background: Secondary
- Active Tab: Primary, Bold, Underline
- Inactive Tab: Text Secondary
- Tab Height: 48
- Tab Padding: 12 horizontal

## Boxes & Containers
- Background: Secondary or Card Background
- Border Radius: 8
- Padding: 12-16
- Margin: 8-16

## Badges
- Background: Accent, Success, Error, Warning (never white)
- Text: White, Bold, 12pt
- Border Radius: 8 (pill shape)
- Padding: 6 horizontal, 2 vertical

## Buttons
- Primary: Background Primary, Text White, Bold
- Secondary: Background Accent, Text White
- Disabled: Background Text Secondary, Text White
- Border Radius: 8
- Padding: 12 horizontal, 8 vertical

## Iconography
- Use consistent icon set (e.g., Lucide)
- Size: 24
- Color: Text Primary or Accent
- Spacing: 8-12 from text

## General Spacing
- Vertical spacing between sections: 16-24
- Horizontal padding: 16

## Usage Guidelines
- Never use white for badges or buttons
- Always use defined colors and spacing
- Titles should be bold and clear
- Cards should have consistent padding, radius, and shadow
- Tabbed interfaces should clearly indicate active tab
- All interactive elements should use primary/accent colors

---

Follow this document for all new and existing components. Refactor any component that does not comply.
